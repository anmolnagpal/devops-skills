# Specs — Backlog Skills

Spec docs imported from anmolnagpal/cloud-skills. These describe future skills but
are not yet authored in the runnable `skills/*.md` format with frontmatter.

To promote a spec into a skill:
1. Pick a spec file (e.g. `aws-cost.md`)
2. Create `skills/aws-cost.md` with proper frontmatter (`name`, `description`, `paths`, `metadata`)
3. Distill the spec into actionable review/scaffold instructions
4. Run `scripts/generate.sh` to refresh Cursor/Codex adapters
