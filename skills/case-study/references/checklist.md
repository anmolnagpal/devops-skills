# Case Study Checklist (pre-publish)

Run this before any case study goes live. Every box ticked or it does not ship.
Checklist owner: Enis. Rules come from `template.md`; the competitor comparison
behind them is in `benchmark.md`.

## A. Container

- [ ] Standalone page at `/case-studies/<client-slug>`, not a modal
- [ ] Unique title tag: "{Client}: {result}, {number} | CloudDrove"
- [ ] Meta description 155 chars or fewer, contains the number
- [ ] OG image 1200x630 with client logo or industry visual
- [ ] Reading time shown
- [ ] Listed on /outcomes with a card that links out (card keeps the category filter)
- [ ] Added to sitemap

## B. Headline and at a glance

- [ ] Headline names the client AND the headline number
- [ ] At a glance block carries three real numbers, no adjectives such as "Lower",
      "Stable", "Tested"
- [ ] Engagement model stated (project | managed | project then managed)
- [ ] Duration stated in months
- [ ] Stack listed
- [ ] "Agents / tools involved" line present where an Intelligence agent or an
      open-source tool was used, absent where none was

## C. Proof

- [ ] One attributed client quote inside the page (name, title, company). An Upwork
      or Clutch source line is optional; "via Upwork" alone is not attribution
- [ ] Every number traceable to a report, invoice, dashboard or client email, with
      the link in internal notes
- [ ] Client approved naming and quote in writing, email link in internal notes
- [ ] NDA check done. If anonymised, "a {industry} company with {N} engineers"

## D. Story

- [ ] Flow is Situation, Challenge (3 to 5 named problems), Before/After table,
      What we built, Outcome, What this means, Key takeaways
- [ ] 800 to 1,200 words
- [ ] Cloud services named explicitly (AWS, Azure, GCP service names, not "the cloud")
- [ ] Names our Terraform modules where used
- [ ] No placeholders, no brackets, no TBD

## E. Close

- [ ] Three key takeaways
- [ ] One related case study link
- [ ] One CTA: free AI-assisted assessment
- [ ] No Upwork badge on the page

## F. After publish

- [ ] LinkedIn post scheduled (05 Content Calendar)
- [ ] If AWS: logged as a launched opportunity in Partner Central (04 AWS Partner Track)
- [ ] Added to 06 Reviews as a referenceable client (y/n)
